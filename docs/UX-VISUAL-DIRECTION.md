# 前端视觉方向：Ink & Daylight

本文件第一节是当前生效的视觉约束，后续所有前端改动以它为准；再往下是设计演进背景，只作为历史记录保留。

## 2026-07-26 完整重设计：Ink & Daylight（当前生效）

此前的鼠尾草绿 + 奶油白读起来发灰、发飘：对比不足、卡片套卡片、装饰元素（环境光球、天气字形）不承载信息，平板横屏还会把日期挤成竖排。本轮推倒重做，视觉目标是**一本被认真排版的私人手账**，而不是一张仪表盘。

### 三条原则

1. **纸与墨**：暖白纸面配真实墨色文字，对比度要撑得住连续读一整页长文，不靠灰度制造"高级感"。
2. **线代替影**：结构由发丝线和留白建立；阴影只留给真正漂浮的东西（手机抽屉、键盘工具条、拖动中的记录片）。
3. **一个强调色**：赭金（拾光 = 拾起光）只用在"此刻可以做的那一件事"上，其余全部让位给文字。

### 色彩

- 浅色：纸 `#f7f4ed` / 表面 `#fffefb` / 墨 `#191713`，发丝线 `#e3ddce`
- 深色：暖炭 `#131211` 而非蓝黑，墨 `#f2ede2`；强调色提亮为 `#e0a458` 以保持对比
- 强调色：`#a85f27`（深色模式 `#e0a458`），用于主按钮、当前状态、活动导航和链接
- 反相面板 `#201d18` 只给 AI 复盘卡：全页唯一的视觉终点
- 心情五级是一条冷→暖的真实色阶（`--mood-1..5`），日历、历史筛选和图例共用同一组变量

### 字体

三层字族，全部随包分发、离线可用：

- **显示层**（日期、标题、月份、统计数字、密码键盘）：`'Fraunces', Georgia, 'Songti SC', …`
  —— Fraunces 老式衬线数字（@fontsource latin 500/600 约 45KB），汉字回落宋体
- **书写层（`--font-write`，正文即书）**：`'Source Serif 4', 'Source Han Serif SC Subset', …`
  —— 日记正文与历史预览默认衬线，对齐 Claude 正文的阅读感（Source Serif 4 是
  Tiempos 一系过渡衬线的开源近亲）。**Android 不预装任何中文衬线**，因此打包了
  自制思源宋体子集（GB2312 全集 6763 字 + CJK 标点，woff2 约 1.3MB，来源与许可见
  `src/assets/fonts/README.md`）；子集外生僻字回落黑体是可接受取舍。
  用户可在设置「书写字体」切回黑体（`:root[data-write-font='sans']`），偏好存本机
- **界面层**：`'PingFang SC', 'HarmonyOS Sans SC', 'Microsoft YaHei UI', …` —— 控件、导航、
  元信息永远无衬线，与正文形成功能分层
- 正文 16.5px / 行高 1.95 / 字距 0.012em；版心 680px（中文一行约 34–38 字）

子集重生成（fonttools + brotli）：

```bash
python -m fontTools.subset SourceHanSerifCN-Regular.otf   --output-file=src/assets/fonts/source-han-serif-sc-regular-gb2312.woff2   --flavor=woff2 --text-file=gb2312-all.txt   --unicodes=U+3000-303F,U+FF00-FF65,U+FE41-FE44,U+2013-2026,U+00B7,U+3007   --layout-features='ccmp,locl,mark,mkmk,kern,palt' --no-hinting --desubroutinize
```

### 形状、材质与动效

- 圆角 4 / 7 / 11 / 16px 四档，比旧版明显收紧，不做气泡
- **纸纹**：`.paper-grain` 全局覆层（z-index 90，feTurbulence 噪点 SVG 平铺，透明度 4–5%），
  浅色黑噪、深色白噪，浏览器把 SVG 栅格化成贴图后按图片平铺，运行时零开销
- 反馈 120ms、组件 200ms、抽屉/页面 320ms；`prefers-reduced-motion` 下全部近乎即时
- hover 只改颜色和背景，不推动布局；书写光标 `caret-color` 用强调色
- **页面进入**：视图切换靠 key 重挂载，`.view-stage` 做 240ms 浮入；历史页月份分组前五组错峰 45ms
- **微交互**：心情选中 260ms 弹跳、标签片 180ms 缩放进入、键盘工具条 220ms 上滑、
  正文聚焦为左侧 2px 赭金竖线（无表单描边）
- **主题切换**：`document.startViewTransition` 整页交叉淡化（配合 `flushSync`），
  不支持或减少动效时直接切换
- **开屏（约 1.26s，可点击跳过）**：晨光从页顶洗下 → 图标掠光一次 → 标题字距从 0.52em
  落定到 0.3em → 墨线自左绘出、一粒赭金火星走完全程 → 日签浮现 → 整体淡出；
  日签文案按当天在年内的序号从 6 句中轮换

### 页面层级

- **写作**：日期（大号衬线，`white-space: nowrap`）→ 标题（无输入框，只有下方发丝线）→ 记录片。每片是左侧一道时间轴细线加一个节点；排序、删除、字数等工具默认透明，悬停或聚焦才浮现，触屏端常驻
- **上下文栏**：心情、标签、往年今日为低调白卡，AI 复盘为反相深色面板
- **专注写作**：`:has()` 直接收走侧栏和上下文栏，日期降为一行小字，只留标题和正文
- **历史**：按月分组的编辑式时间流，日期数字用衬线，条目之间只有一条发丝线
- **日历**：心情作为格子左侧色条（手机端为底部短横），不整块染色；今天是墨色圆点
- **设置**：状态条 + 卡片网格，输入框使用下沉底色
- **应用锁**：独立整页（`z-index 80`，纸面背景 + Fraunces 数字键盘）。4–6 位数字密码经
  PBKDF2-SHA256（120k 次、随机盐）哈希后只存本机；这是防翻看的进入门，不加密日记数据。
  冷启动必锁，切后台超过 30 秒回来重锁；连错 5 次冷却 30 秒；不提供应用内找回
- **时段词**：今天的日期副行随时刻显示 清晨/上午/午后/傍晚/夜里/深夜

### 响应式契约

| 断点 | 布局 |
| --- | --- |
| ≥1200px | 252px 侧栏 + 弹性正文 + 322px 上下文栏，三区独立滚动 |
| 900–1199px | 214px 侧栏 + 正文 + 274px 上下文栏 |
| 700–899px（平板竖屏） | 侧栏收成 74px 图标轨，正文与上下文栏保持双栏；上下文栏隐藏提示语和引语 |
| ≤699px / 横向 ≤820px / 横向且高 ≤520px | 单栏；侧栏变抽屉（z-index 45，盖住底栏），底部四项标签栏；心情与标签压成两条窄行 |

横屏手机（如 Redmi Note 11T Pro 实测 895×393 CSS px）宽度落在平板区间但高度只有 393px，必须靠 `(orientation: landscape) and (max-height: 520px)` 拉回紧凑布局。这条断点在 `journal-ui.css` 和 `App.tsx` 的 `compactNavigation` 里各写一份，改动时必须同步。

- 侧栏是自身唯一的滚动容器，列表不得被 flex 压缩
- 输入法唤起时（`:root[data-keyboard-input]`）隐藏底部标签栏并取消其占位
- 所有触控目标 ≥44px

### 安全区

Android 15（targetSdk 35+）和 iOS 全面屏都是 edge-to-edge，`index.html` 已设 `viewport-fit=cover`，
因此 **`env(safe-area-inset-*)` 必须在所有断点处理，而不是只在紧凑端**：横屏时状态栏会落在左右两侧，
只补顶部会让标题压住系统时钟。当前落点：

- `.topbar`：`height: calc(基准 + inset-top)` + `padding-top: inset-top`，让粘性顶栏自己盖住状态栏
- `.sidebar`：顶部、底部、左侧三向内边距
- `.writing-column` / `.insight-column` / `.page-container`：左右用 `max(基准, inset)`
- `.mobile-nav` / `.keyboard-format-toolbar`：底部与左右

### Android 原生启动屏

`android/app/src/main/res/values/colors.xml` 的 `splash_background` 必须跟 Web 主题色同步，
否则冷启动会先闪一下旧配色。当前浅色 `#F7F4ED`、`values-night` 深色 `#131211`，
状态栏图标明暗由 `@bool/splash_light_status_bar` 跟随。

### 实现约束

- 运行时样式只有两个文件：`src/index.css`（token 与元素基线）和 `src/journal-ui.css`（唯一组件层）
- `App.css`、`editorial-ui.css`、`journal-reference.css`、`performance.css`、`redesign.css`、`ui-v2.css` 已删除，不要再新增并行样式层

- 列表与卡片预览统一走 `journalPreviewText()`，避免把记录片分隔符 `---` 渲染给用户

## 设计演进背景（历史记录，不再作为约束）

## 2026-07 完整重设计：Editorial Paper

当前视觉统一为“编辑纸本”：像一本被认真排版的私人日记，而不是数据仪表盘或技术演示页。此前 Soft Tech、开源参考和移动端修补记录保留为设计演进背景；实现以本节为最新约束。

### 视觉系统

- 画布使用暖灰纸色，正文使用不透明象牙白；取消常驻网格、环境光、玻璃和发光装饰
- 墨色接近深灰绿，鼠尾草绿只用于当前状态和主操作，陶土色只用于日期与时间线锚点
- 标题采用宋体/衬线回退，正文和控件采用无衬线；不依赖在线字体才能成立
- 圆角分为 8 / 12 / 16px 三档，阴影只用于正文纸面和移动抽屉，普通信息块依靠留白与细线分层
- AI、心情、标签、统计都属于注脚层；正文、日期和历史文本永远先于它们

### 页面层级

- 写作：首页只强调日期、标题和正文；照片、提示、心情、标签、时间回声与 AI 按书写流程依次出现
- 历史：按月份分组的编辑式时间流，条目像目录而不是卡片墙；照片只占窄缩略图
- 日历：使用清晰的月历表格，不用大面积心情色块；已有记录由小圆点和短标题提示
- 设置：改为纵向设置组，状态、连接、导出和本地数据使用一致行结构

### 响应式契约

- 320–699px 手机：顶部 56px、底部 64px；无侧栏、无背景网格；内容左右留白 16px，正文纸面可贴近边缘
- 700–899px 竖屏平板：176–192px 固定导航 + 单列正文；上下文在正文后两列排列
- 900–1199px 横屏平板：188–208px 导航 + 弹性正文 + 260–288px 注脚栏；正文和注脚栏分别滚动
- 1200px 以上桌面：224px 导航 + 最大 1320px 工作区；正文宽度优先，右栏不超过 304px

### 状态与可访问性

- 保存、本地失败、同步中、离线和已同步只使用文字、圆点和颜色三种共同信号
- 空日记显示三个可点击写作起点；有正文后提示条自动消失，不引起编辑器宽高跳变
- 固定底栏不得覆盖编辑器页脚；软键盘、系统栏和安全区均通过 `env(safe-area-inset-*)` 预留
- 所有操作目标至少 44px；键盘焦点可见；减少动效模式关闭非必要过渡

### 实现状态（2026-07-22）

- 运行时样式已收敛为 `src/editorial-ui.css`；`App.css`、`ui-v2.css` 与 `journal-reference.css` 仅保留为历史实现，不再进入 CSS 级联
- 全局颜色、字体与基础焦点规则集中在 `src/index.css`；默认字体使用系统回退，不依赖在线字体加载
- 已在 390×844、768×1024、1024×768、1440×900 四档真实视口验收写作页，并回归手机历史时间线、深色模式、本地存储失败和时间回声
- 构建、Lint、单元测试、浏览器 E2E 与 PWA 离线刷新均通过

### 多记录片与三栏滚动（2026-07-22）

- 横屏平板和桌面采用左、中、右三个独立滚动区域：左栏浏览导航与最近记录，中栏容纳自然增高的记录片，右栏浏览心情、标签、往年今日和复盘
- 手机由页面承担纵向滚动，记录片正文不再内部滚动；心情与标签前置到标题和正文之前
- “另起一段”创建独立纸片，支持按钮排序和长按拖动；每片显示多次写作时间，时间精确到秒
- 全局同步状态只放在顶部；编辑器页脚只说明本地保存，AI 卡片只说明同步后能否复盘
- 右栏取消 emoji 实时滤镜，禁止与外层页面形成嵌套滚动，以降低 Android WebView 滚动卡顿

### 手机实机输入与动效收口（2026-07-22）

- 正文增高采用“只增长、失焦后再收缩”的高度策略，输入时禁止把 textarea 临时设为 0；第二记录片超过 302 字时页面和光标位置必须稳定
- 写作时间移到每张记录片末尾，以“写于 / 续写 + HH:mm:ss”呈现；开头只保留记录片编号和移动操作
- 记录片使用低饱和绿色错位底片形成磁吸瓷片层次；长按后轻微抬起，换位采用 220ms FLIP 过渡
- 手机抽屉使用 260ms 减速进入和短遮罩淡入；底部四项只做短距离抬升、图标缩放与页面淡入，不使用滤镜或长距离滑动
- 每片内部提供 Markdown 加粗/斜体和三档整片文字颜色；标签保持可选且不强迫用户预先分类

### 键盘与行内时间二次收口（2026-07-22）

- 正文停笔后使用无输入框轮廓的纸面阅读态；点击正文才进入编辑态，焦点只通过整张记录片的轻微边界变化表达
- 记录片顶部显示第一次开始时间；每次停笔按正文偏移在对应文字后显示紧凑的 `HH:mm:ss` 徽标，多个会话各自保留位置
- 标题、标签、搜索或正文等任意文字输入获得焦点时，隐藏“今日 / 日历 / 历史 / 设置”底栏，避免应用导航和 Android 输入法争抢同一区域
- 加粗、斜体、颜色和“完成”组成固定的键盘附件栏；附件栏只在正文编辑期间出现，并随视觉视口停靠在输入法上方

### 成熟交互系统收敛（2026-07-22）

本轮参考 Material 3 的状态层、Web 弹簧近似曲线与转场原则，以及 Apple HIG 对“动效用于状态、反馈和层级说明”的约束；保留拾光的纸本视觉，不复制任何平台品牌外观。

- 全局动效收敛为快速反馈 140ms、组件切换 220ms、页面/抽屉 280ms，并统一使用标准曲线与弹簧近似曲线
- 默认卡片保持低海拔纸面；只有聚焦和拖动提升阴影，按压使用轻微缩放，禁止 hover 推动布局
- 手机底部导航使用图标后的活动胶囊表示当前页，不再给整格铺色；文字和图标位置保持稳定
- 阅读/编辑切换、键盘附件栏和页面进入只使用短距离透明度/位移，`prefers-reduced-motion` 下缩短到近乎即时
- 纸片、上下文卡、按钮、心情选择与滚动条统一边框、圆角、状态反馈和颜色使用，避免每个模块拥有独立视觉语言

### 可感知的层级重构（2026-07-23）

上一轮只收敛阴影、圆角与动效参数，实机前后差异不足。本轮重新建立可直接辨认的三层结构，并要求截图和真机都能肉眼验收：

- 左栏改为深森林色“书封”，以高对比导航锚定产品身份；激活项使用陶土色书签线，不再与正文纸面混成一层
- 中栏日期使用暖色扉页，标题使用陶土色装订线，正文记录片成为唯一高亮纸面；右栏统一降为低海拔注脚卡
- 记录片增加可见磁吸侧边与聚焦抬升，拖动时放大位移、旋转和投影差异，但正文输入期间不运行持续动画
- 手机底栏改为带外边距和投影的悬浮导航岛，当前图标落在深色胶囊中；软键盘出现时仍完全隐藏
- 手机空记录片高度从 260px 收敛到 180px，保证连续另起多段时能看到相邻关系；长文继续由内容自然撑高
- 320–380px 不再隐藏任何写作时间，空间不足时允许自然换行

### 产品壳层、图标与启动体验（2026-07-23）

- Android 原生启动层不再显示 Capacitor 标志，改为森林绿品牌底色与“日记本＋晨光”应用图标，避免原生层和 Web 层之间闪白
- Web 品牌开屏控制在约 1 秒，只在每次应用会话首次冷启动出现；可点击跳过，减少动效模式缩短至 140ms，不阻塞长期写作
- 导航图标统一为“日记、日历、资料库、调节”四个语义，全部使用相同的 18px 图形、1.8px 描边和 32px 状态容器
- 手机当前标签以深绿图标容器和稳定文字表示，平板侧栏以陶土书签线和浅色图标容器表示；切换状态不改变文字位置
- 切换页面前记录各页面滚动位置，返回时恢复；再次点击当前标签则平滑回到顶部，打开具体日期始终从当天页首开始

## 目标感受

柔软的感知 × 精确的计算。产品应让人感到信息在流动、被整理、正在生成，但写作区域必须安静、可信、可长时间使用。

## 视觉规则

- **背景**：暖白或低饱和深色，不使用纯黑大面积压迫
- **材质**：常驻导航和正文使用不透明纸面；磨玻璃只允许用于短时浮层，不覆盖正文阅读区
- **色彩**：一套克制的中性色，加一组代表“运算激活”的冷暖渐变
- **纹理**：细颗粒或极淡网格，作为背景层，不能干扰文字
- **光感**：AI 复盘只使用克制的边框和浅色面，普通保存状态保持安静
- **结构**：技术网格、细线边界、明确间距；避免卡片堆叠和无意义装饰
- **图文**：文字优先；图片是可选的记忆锚点。只有用户添加照片时才显示图文卡片，不为无图日记制造空白占位
- **动效**：同步、AI 思考、保存使用短而可解释的过渡，不做持续闪烁
- **性能**：正文输入区不使用毛玻璃、发光阴影或持续动画；页面切换只保留一次短淡入，滚动优先于装饰

## 信息层级

1. 今天的日期和写作区域
2. 正文阅读/输入体验
3. 心情与标签
4. 同步状态
5. AI 复盘入口

AI 不应在视觉上抢过日记正文。任何 AI 状态都必须能回答“正在做什么、是否完成、失败后怎么办”。

## 响应式原则

- 手机优先保证单列写作、键盘输入和状态栏安全区
- 平板竖屏使用“导航侧栏 + 写作主列 + 上下文卡片”的 master-detail 结构，不使用手机底栏
- 平板横屏使用“窄导航 + 弹性正文 + 窄洞察栏”，正文优先获得宽度，洞察栏独立滚动
- PC 才展示完整侧栏、日历和洞察区域
- 所有关键操作同时支持触控和键盘焦点

### 平板工作台

- 平板竖屏保留约 224px 导航侧栏，正文使用单列滚动，心情/标签在正文后以两列上下文卡片呈现
- 平板横屏导航收窄到约 220px，正文与右侧洞察栏按可用宽度弹性分配，右栏约 280px 并独立滚动
- 顶栏在横屏压缩为 56px；编辑卡片锁定在可视高度内，正文区域独立滚动
- 只有手机尺寸使用底部导航；平板不把底栏覆盖在编辑器上

### 动效节奏

- 冷启动直接进入写作界面，不用品牌开屏阻塞首次输入
- 页面切换不使用位移或滤镜动画；状态变化只允许短时颜色/透明度过渡
- 减少动效模式关闭全部非必要动画和过渡；输入和滚动期间不运行持续动画

### 图标系统

- 应用内统一使用 Lucide 线性图标，保持一致线宽、视觉尺寸、圆角容器和激活状态
- Android 启动器图标使用象牙色日记本、晨光折页、棕色书脊和鼠尾草绿书签，不放文字，不使用旧 Capacitor 标志
- 普通、圆形和应用内品牌图标复用同一张经过小尺寸优化的图像，系统裁切后仍须保留日记本轮廓与书签
- 品牌图标只承担识别，保留纸张和皮革的轻微材质，不添加持续发光，以保证桌面小尺寸下清晰

## 前端重构前的验收问题

- 用户打开后是否一眼知道该写在哪里？
- 保存和同步是否能被理解而不是被猜？
- AI 入口是否有吸引力但不打断写作？
- 长文、空状态、离线、错误和深色模式是否同样成立？
- 添加照片后是否仍然能快速回到文字，且无图日记不被图片入口打扰？

## 2026-07 前端可靠性迭代

- 编辑器标题和正文有稳定的可访问名称；移动抽屉关闭时同步设置 `aria-hidden` 与 `inert`，平板竖屏保留可访问的固定侧栏
- “记录完整 4/4”不再把标题、正文、心情和标签当作必填任务；心情和标签保持可选
- AI 状态文案只在提示词实际复制、窗口实际打开后显示成功；静态说明不会提前声称“已复制”
- 本地保存失败显示“尚未保存到本机”，而不是与离线同步混用；用户仍可继续编辑并重试

## 2026-07 多端视觉收敛

- 正文纸面取消发光焦点和大面积毛玻璃，AI 卡片降为浅色辅助面，确保标题和正文始终是第一视觉焦点
- 390px 手机收紧空白写作区，使保存状态和写作操作不被底部导航覆盖；768px 竖屏平板在首屏露出心情/标签上下文
- 关键触控目标不小于 44px；长标题、标签和 URL 必须换行或截断，不得制造横向滚动
- 1024px 横屏平板和 1440px 桌面让洞察栏独立滚动，日期保持单行，并为系统栏、手势导航和软键盘预留安全区
- 常驻环境光、同步脉冲和页面入场动画全部关闭；桌面 hover 不再推动布局

## 2026-07 开源日记设计参考升级

本轮参考 memoria 的安静纸面、Memos 的低摩擦时间流，以及 Journiv 的 On This Day 回顾层级。只借鉴通用交互模式，不复制品牌资产、专有文案或源代码。

- 写作页继续使用“左侧导航 + 中央纸面 + 右侧上下文”，但减少仪表盘感：日期与正文由细线衔接，卡片降低圆角和阴影，正文纸面保持唯一主焦点
- 历史页由均质卡片网格改为“月份分组 + 纵向时间轴”，让日期关系先于图片和标签；手机端折叠为单列时间流
- 右侧新增“时间回声”：有往年同日记录时展示标题与摘要并允许回看；没有记录时显示克制的未来提示，不使用虚构洞察
- AI 复盘卡取消强烈渐变和发光，使用纸面、左侧双色细线和明确状态，让 AI 始终低于正文与记忆回看
- 新的视觉覆盖集中在 `src/journal-reference.css`，作为现有样式逐步迁移的最终层；稳定后再合并旧样式，避免一次性重写造成三端回归

### 本轮验收

- 390px 手机：标题、正文、保存状态和底部导航不互相覆盖；历史时间轴不产生横向滚动
- 768px 平板：固定侧栏保持可访问，写作与上下文仍能在首屏建立清晰层级
- 1440px 桌面：纸面正文宽度适合长文，时间回声和 AI 复盘不抢正文焦点
- 深色模式、减少动效、无图日记、图片日记、空历史和离线状态均保持可用

## 2026-07 手机与平板二次打磨

本轮修复“桌面布局被压缩到移动端”的根因，并明确截图与真实视口的区别。

- 手机端取消主内容网格背景，历史页标题降为 36px，月份、筛选和时间流卡片使用更紧凑的单列节奏
- 手机底部导航固定贴合真实视口底部，页面内容预留安全区；视觉回归截图使用 viewport 截图，不再用 full-page 截图呈现固定导航，避免底栏看似悬在长页面中段
- 手机空白编辑器在首屏完整露出保存状态、“继续写”和“另起一段”；日期切换保留 44px 触控目标，专注入口在窄屏隐藏
