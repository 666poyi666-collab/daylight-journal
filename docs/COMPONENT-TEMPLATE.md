# 组件文档模板

新增复杂组件时，在对应模块的 `MODULE.md` 或组件旁补充：

```md
# ComponentName

## 用途
一句话说明它解决的用户问题。

## 状态
- 默认
- 加载/同步中
- 空状态
- 错误/离线
- 禁用/只读

## 输入与输出
列出 props、事件、异步请求和副作用。

## 响应式行为
说明手机、平板、PC 的布局变化，以及键盘和触控行为。

## 可访问性
说明语义元素、可见焦点、键盘操作和 aria 文案。

## 验收
给出可执行的手工步骤或测试命令。
```

日记编辑器尤其必须说明：自动保存、同步失败不丢稿、继续写、另起一段、长文本滚动和键盘遮挡。
