## 新 Bug 模板

```md
### BUG-xxx：一句话标题

- 状态/严重度：
- 用户动作：
- 预期：
- 实际：
- 复现步骤：
- 端与版本：
- 请求 URL/状态码：仅记录脱敏后的必要部分
- 关键状态变化：
- 根因：
- 修复范围：
- 回归证据：测试命令、用例或截图路径
```

禁止记录真实日记正文、令牌、Cookie、浏览器会话、个人公网地址或未经裁剪的生产日志。
