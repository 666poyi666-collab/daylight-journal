# 产品定义

## 一句话

让用户在 10 秒内开始记录，在一天结束时用 ChatGPT 看见自己的行动、情绪和下一步。

## 第一阶段范围

### 必须有

- 今日写作：标题、正文、心情、标签
- 可选添加一张日记照片；文字仍是默认主角，图片用于记忆入口和历史卡片识别
- 自动保存，退出后可继续写
- 另起一段，避免“同一天只能有一篇”的僵硬限制
- 日历定位日期、历史列表和搜索
- 本地优先，跨端同步
- 固定进入 ChatGPT「日记」项目的 AI 复盘入口

### 明确不做

- 第一阶段不接入 Time One 和滴答清单
- 不做完整所见即所得富文本编辑器；记录片内只提供 Markdown 加粗/斜体，以及整张记录片三档文字颜色
- 不做相册流或多图管理；第一阶段每篇最多一张可选封面图
- 不做账号体系、社交、公开发布
- 不做自动生成日记或替用户改写原文
- 不做 Obsidian 双向写入；先保证 Markdown 导出

## 核心交互

### 写作

打开应用默认到今天。输入标题或正文即形成记录，500ms 防抖保存。重新打开同一天时默认继续编辑，不自动拆成新篇。

### 记录片与另起一段

一天由一个或多个可排序记录片组成。正文会随内容自然增高；手机由页面滚动，横屏平板和桌面由固定高度的中栏独立滚动。

“另起一段”创建新的记录片，不再向正文插入 Markdown 分隔线。记录片可通过上移/下移操作排序，触屏端也支持长按拖动手柄。删除有内容的记录片前必须确认。

每个记录片保存多次写作会话。记录片顶部显示第一次开始时间；每次失焦或点击“完成”视为停笔，并保存停笔时间及当时的正文字符偏移。阅读态按照偏移把 `HH:mm:ss` 时间徽标直接排在对应文字后面；稍后继续写并再次停笔时，在新文字后追加新的时间徽标。时间不写入正文纯文本。

正文采用阅读态和编辑态：停笔后回到无输入框轮廓的纸面阅读态，点击正文才进入编辑态。任意文字输入框获得焦点时底部四项导航隐藏；编辑正文时，加粗、斜体、颜色和“完成”集中到输入法上方附件栏。退出输入后恢复底部导航。

记录片是可移动的磁吸纸片：长按手柄后纸片随手指轻微抬起，跨过另一片时以短动画重新排列。输入过程中正文只向下增高，不得为了计算高度临时归零，也不得让页面滚动位置跳回顶部。

### AI 复盘

点击入口前先保存并同步当前内容，复制复盘提示词，然后打开固定的 ChatGPT 项目 URL。ChatGPT 通过用户在项目中启用的「拾光日记」Cloud OAuth 连接器调用 Journal 读取工具和完整正文 Resource；电脑关机后该连接器仍可读。生产 Cloud MCP 保持只读，创建、追加和修改仍由日记应用完成。复盘同时读取当天记录与近期记录，区分事实、推断和证据不足，并输出长期模式与“长期记忆更新候选”；当前只提出候选，不声称已经写入永久记忆。

### 时间流与往年今日

历史页按月份组织为连续时间流，日期、正文摘要、心情、标签和可选照片共同承担回看线索，不再把日记呈现为无时间关系的卡片墙。

写作页在存在同月同日的往年记录时显示“往年今日（时间回声）”，用户可以直接回到那一天；没有往年记录时明确解释该功能，不伪造内容，也不把连续记录天数变成强制目标。
