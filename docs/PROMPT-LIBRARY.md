# 提示词资产库

提示词不是一次性聊天内容，而是项目资产。每条提示词包含：用途、前置上下文、正文、预期输出、禁止事项和验证记录。

## 日记复盘 v1

**用途**：读取指定日期日记并生成诚实复盘。

**正文**：

```text
请使用“拾光日记”连接器读取今天的日记。
请基于实际读取到的内容，输出：
1. 今日概括
2. 主要事件与行动
3. 情绪变化
4. 做得好的地方
5. 可以改进的地方
6. 明天最值得关注的一件事

不要编造日记中没有的信息；如果没有日记，明确说没有读取到记录。
只读，不修改任何数据。
```

**验证**：ChatGPT 项目中已实测调用 `list_recent_journals`；空数据时返回空数组并明确说明未读取到记录。

## 新提示词登记规则

- 先写目标和工具边界，再写语气。
- 明确禁止编造、越权写入和隐式操作。
- 先在真实项目中验证，再登记为稳定版本。
- 修改提示词时保留版本号和变更原因。

## 日记复盘 v2（当前）

**用途**：从单日复盘升级为有证据边界的长期个人复盘。

**前置上下文**：先调用 `get_journal_by_date` 读取指定日期的记录片和写作时间，再调用 `list_recent_journals` 获取近期脉络。连接器只读。

**预期输出**：今日全景、行动与选择、情绪轨迹、具体优势、阻力与盲点、长期模式、未完成事项、下一步、长期记忆更新候选，以及值得继续思考的问题。

**边界**：区分原文事实、合理推断和证据不足；不做医学诊断；不声称“长期记忆更新候选”已经写入永久记忆。运行时正文由 `src/journal/review.ts` 生成，并由单元测试锁定关键约束。

**变更原因**：用户要求复盘不再停留在简短总结，并为后续个人复盘系统保留可迭代的记忆候选结构。
